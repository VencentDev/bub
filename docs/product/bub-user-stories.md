# Bub Product User Stories

This document is the master product guideline for Bub. Feature planning, tickets, design decisions, and implementation work should trace back to these user stories unless a later product decision supersedes them.

## Product

**Name:** Bub

**Tagline:** Closer, one tap away.

## Vision

Bub is an exclusive messaging platform designed for couples. Unlike traditional messaging apps, each account can only be paired, or tethered, with one other account, creating a private digital home where couples can chat, share moments, send vibrations called Bubs, doodle together, and safely store intimate memories.

## Roles

Current:

- User

Future:

- Admin
- Moderator, if community features are ever added

## Version 1.0 MVP Scope

Focus on these first:

- Authentication
- One-to-one Tether
- Home
- Chat
- Bub vibration
- Today's Moment
- Safe private vault
- Home Widgets
- Notifications
- Settings

## Future Version 2.0 Ideas

- Heartbeat: Hold the heart button and your partner's phone vibrates in the same rhythm.
- Sleep Together: If both users are idle at night, the bears cuddle and the app enters a sleeping state.
- Shared Music: Listen to the same song together.
- Journey Map: Timeline of places you have been together, optional and privacy-conscious.
- Time Capsule: Write messages that unlock on a future date.
- Mini Games: Tic-Tac-Toe, Doodles, Memory Game, Would You Rather.
- Relationship Timeline: Automatically build a scrapbook from Moments, Safe uploads, and anniversaries.
