# Epic 13: Profile

Profile controls personal identity and relationship date metadata.

## US-055 Edit Profile

As a user, I want to edit my profile so that my partner sees the right identity details.

### Acceptance Criteria

- User can edit name.
- User can edit username.
- User can edit avatar.

## US-056 Relationship Date

As a user, I want to set our relationship date so that Bub can show how long we have been together.

### Acceptance Criteria

- Relationship date powers together count, for example: `623 Days ❤️`.

## US-057 Anniversary Reminder

As a user, I want anniversary reminders so that Bub celebrates relationship milestones.

### Acceptance Criteria

- User receives anniversary notification, for example: `Happy 1 year ❤️`.
