# Epic 8: Moments

Moments are shared daily photos that help couples keep a lightweight visual history.

## US-035 Upload Today's Moment

As a user, I want to upload today's moment so that we can preserve one daily picture.

### Acceptance Criteria

- User can upload one daily picture.

## US-036 React to Moment

As a user, I want to react to a moment so that I can respond emotionally.

### Acceptance Criteria

- Supported reactions include ❤️, 🥰, and 😍.

## US-037 View History

As a user, I want to view past moments so that I can revisit our history.

### Acceptance Criteria

- User can view a calendar.
- User can view a monthly timeline.
