# Epic 11: Notifications

Notifications keep partners aware of messages, Bubs, Safe activity, and quiet hours.

## US-045 Receive Message Notification

As a user, I want to receive message notifications so that I know when my partner messages me.

### Acceptance Criteria

- User receives notifications for new messages.

## US-046 Receive Bub Notification

As a user, I want to receive Bub notifications so that I feel the signal immediately.

### Acceptance Criteria

- User receives a Bub notification.
- Notification uses a special vibration pattern.

## US-047 Receive Safe Notification

As a user, I want to receive Safe notifications so that I know when memories are added.

### Acceptance Criteria

- Notification includes ❤️.
- Notification copy may say: `3 memories were added.`

## US-048 Quiet Hours

As a user, I want quiet hours so that I can mute notifications.

### Acceptance Criteria

- User can mute notifications during quiet hours.
