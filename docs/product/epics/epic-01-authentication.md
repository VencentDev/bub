# Epic 1: Authentication

Authentication lets new and returning users securely access Bub.

## US-001 Create Account

As a new user, I want to create a Bub account so that I can start using the application.

### Acceptance Criteria

- User can register with Google.
- User can set a username.
- User can set a display name.
- User receives email verification.
- User cannot continue until the account is verified.

## US-002 Login

As a returning user, I want to login so that I can access my Bub.

### Acceptance Criteria

- User can login with Google.
- Authentication is secure.
