# Epic 10: Widget

Widgets bring Bub interactions and relationship context to the device home screen.

## US-041 Home Widget

As a user, I want a home widget so that I can see today's moment without opening the app.

### Acceptance Criteria

- Displays Today's Moment.

## US-042 Bub Widget

As a user, I want a Bub widget so that I can send a Bub instantly.

### Acceptance Criteria

- Displays a heart button.
- Tapping sends a Bub instantly.

## US-043 Countdown Widget

As a user, I want a countdown widget so that I can see how long we have been together.

### Acceptance Criteria

- Shows together count, for example: `532 Days ❤️`.

## US-044 Mood Widget

As a user, I want a mood widget so that I can share or see a quick relationship mood.

### Acceptance Criteria

- Displays mood text, for example: `Missing You 🥺`.
