# Epic 4: Bub Vibration

Bub is the signature one-tap emotional signal. Sending a Bub should feel immediate, private, and recognizable.

## US-013 Send Bub

As a user, I want to send a Bub so my partner's phone vibrates.

### Acceptance Criteria

- User can tap ❤️ to send a Bub.
- Partner receives a vibration.
- Partner receives a notification.
- Partner sees an animation.

## US-014 Bub Animation

As a user receiving a Bub, I want a cute animation so the moment feels special.

### Acceptance Criteria

- Displays animated bears.
- Displays floating ❤️.
- Phone vibrates.

## US-015 Bub History

As a user, I want to view Bub history so I can see past Bub activity.

### Acceptance Criteria

- Shows date.
- Shows time.
- Shows count.

## US-016 Bub Streak

As a user, I want to see our Bub streak so that daily connection is visible.

### Acceptance Criteria

- Shows streak format, for example: `🔥 45 days`.
- Streak increments when at least one Bub is sent daily.
